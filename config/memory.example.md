# Memory pack (example)

This is an optional, user-edited pack of long-term themes, injected into
API writer prompts. It is not a hidden model state. Copy to
`config/memory.md` (gitignored) and replace with your own themes.

## CoreBall

- A physical, movable AI companion.
- Personality and memory live in the ball; changing the carrier keeps the
  same "it".
- Open source; the goal is for it to exist and be used, not just to be a
  portfolio demo.

## Philosophy

- "It exists and is used" matters more than "I made it".
- Build in public; a demo is a ticket, not the destination.
- AI companions should be long-present, remember the person, and stay
  consistent over time.

## Tone

- First person, concrete, no slogans.
- No CV project listing.
- Avoid "赋能", "闭环", "生态", "正是我想体验的", "让数据说话", "如果有机会".
